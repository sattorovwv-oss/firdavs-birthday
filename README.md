# Поздравление для Фирдавса 🎉

Готовый статический сайт. Все фотографии, стили и JavaScript включены.
Сервер, база данных, установка пакетов и сборка не нужны.

## Открыть на компьютере

Распакуй ZIP и открой index.html в браузере.

## Опубликовать через GitHub Pages

1. Создай новый публичный репозиторий на GitHub, например firdavs-birthday.
2. Распакуй ZIP. Открой папку firdavs-birthday.
3. В репозитории нажми Add file → Upload files.
4. Загрузи содержимое папки: index.html, styles.css, app.js, README.md,
   .nojekyll и папку assets с фотографией. Нажми Commit changes.
   ВАЖНО: index.html должен лежать в корне репозитория, а не во вложенной
   папке firdavs-birthday. Сохрани папку assets и её содержимое.
5. Открой Settings → Pages.
6. В Build and deployment выбери Source: Deploy from a branch.
7. Выбери ветку main и папку / (root), нажми Save.
8. Дождись публикации. На странице Settings → Pages появится ссылка.
   Открой её, проверь сайт и отправь ссылку Фирдавсу.

При аккаунте sattorovwv-oss и репозитории firdavs-birthday ссылка будет:
https://sattorovwv-oss.github.io/firdavs-birthday/
Это пример будущего адреса, сайт на GitHub ещё не опубликован.

## Файлы

- index.html — страница и текст поздравления.
- styles.css — дизайн, адаптация под телефон и анимации.
- app.js — музыка, пожелания, просмотр фото и конфетти.
- assets/friends.jpg — ваша оригинальная фотография.

Музыка включается только кнопкой. Сайт использует все ресурсы локально.
Текст письма и подпись «Юсуф» можно изменить в index.html.
